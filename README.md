# nexus7
NEXUS-7 terminal

## Dé

`index.html` est un dé 3D à utiliser sur iPhone : touchez l'écran, le dé tourne pendant 1,5 seconde puis s'arrête sur une face tirée au hasard, avec le bruit des rebonds sur le tapis (bouton Son/Muet en haut à droite).

Le niveau 2, choisi en haut à gauche, tire un numéro de 1 à 49 sur une boule de loto qui défile pendant 1,5 seconde avant de s'arrêter.

Ouvrez la page dans Safari, puis Partager > Sur l'écran d'accueil pour l'utiliser comme une app.
